# 🔐 crypto-scan

**crypto-scan** es un escáner de red avanzado basado en **Nmap**, con una interfaz interactiva en terminal (TUI), diseñado para **pentesting ético**, **auditorías de red** y **aprendizaje en ciberseguridad**.

El proyecto actúa como un wrapper profesional de Nmap, integrando detección de servicios, scripts NSE, análisis de vulnerabilidades y exportación automática de resultados, todo con una experiencia visual clara y moderna en la terminal.

---

## ✨ Características

- 🎨 Interfaz gráfica en terminal (TUI)
- 🖥️ Banner ASCII personalizado (`cryptod3stiny`)
- 🔍 Descubrimiento de hosts
- 🚪 Escaneo de puertos TCP (rápido y completo)
- 🧠 Detección de servicios y versiones
- ⚠️ Escaneo de vulnerabilidades (NSE)
- 🖥️ Detección de sistema operativo
- 📡 Escaneo UDP (puertos comunes)
- 📂 Ejecución de scripts NSE por defecto
- 📄 Exportación automática de resultados (XML y TXT)
- 🧹 Parseo inteligente (solo información relevante)
- 🧩 Arquitectura modular y escalable

---

## 🛠️ Tecnologías utilizadas

- **Python 3**
- **Nmap**
- **Nmap Scripting Engine (NSE)**
- **Rich** (UI en terminal)
- **PyFiglet** (ASCII Art)
- **lxml** (parseo XML)
